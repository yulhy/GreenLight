
# GreenMate 데이터 출처 및 가정

## 1. 문서 목적

GreenMate의 탄소배출계수와 비용 데이터의 출처,
기준연도, 단위 및 계산 가정을 기록한다.

## 2. 데이터 등록 원칙

모든 데이터는 다음 정보를 함께 기록한다.

- 데이터 항목
- 출처명
- 원문 URL
- 기준연도
- 배출계수 또는 비용
- 계산 단위
- 적용 범위
- 계산 가정
- 데이터의 한계

## 3. 데이터 출처 표

| 카테고리 | 항목 | 출처 | 기준연도 | 단위 | 비고 |
|---|---|---|---|---|---|
| transport | 승합차 | 조사 후 기록 | YYYY | 정의 필요 | 적용 조건 |
| food | 소고기 식사 | 조사 후 기록 | YYYY | 정의 필요 | 식사 구성 |
| lodging | 숙박 | 조사 후 기록 | YYYY | 정의 필요 | 숙박 기준 |
| tableware | 다회용 식기 | 조사 후 기록 | YYYY | 정의 필요 | 사용 및 세척 가정 |

## 4. 계산 가정 기록

각 항목의 데이터에는 다음 질문에 대한 답이 있어야 한다.

- 1단위는 무엇을 의미하는가?
- 참가 인원에 따라 어떻게 환산하는가?
- 이동거리 또는 사용횟수가 필요한가?
- 비용은 실제 가격인가, 참고 추정값인가?
- 어떤 조건에서 적용 가능한가?
- 데이터의 불확실성은 무엇인가?

## 5. 데이터 검토 체크리스트

- [ ] 출처가 확인되었는가?
- [ ] 기준연도가 기록되었는가?
- [ ] 단위가 명확한가?
- [ ] 계산식과 가정이 문서화되었는가?
- [ ] 카탈로그의 필드와 일치하는가?
- [ ] 데이터가 MVP 시연 시나리오에 적용 가능한가?
