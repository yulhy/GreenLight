
# GreenMate 프로젝트 개요

## 1. 서비스명

GreenMate

## 2. 한 줄 소개

AI와 함께 행사 계획을 세우고, 탄소배출량과 비용을 분석하여
현실적으로 실행 가능한 저탄소 행사 대안을 추천하는 서비스.

## 3. 해결하려는 문제

행사를 기획할 때 주최자는 장소, 이동수단, 식사, 숙박,
소모품 및 예산을 고려한다.

하지만 다음과 같은 문제를 동시에 판단하기 어렵다.

- 어떤 항목에서 환경 영향이 가장 크게 발생하는가?
- 친환경적인 대안은 무엇인가?
- 대안을 선택하면 비용이 얼마나 달라지는가?
- 행사 규모와 예산에 맞게 실제로 실행할 수 있는가?
- 환경을 개선하면서 편의성을 유지할 수 있는가?

GreenMate는 이러한 의사결정을 지원한다.

## 4. 핵심 사용자

### 주요 사용자

- 대학 MT 및 OT 기획자
- 소규모 단체행사 운영자
- 동아리 및 학생회 행사 담당자

### 사용자 목표

- 행사 계획을 쉽게 입력한다.
- 현재 계획의 탄소배출량과 비용을 확인한다.
- 환경 영향이 큰 항목을 파악한다.
- 실행 가능한 대안을 비교한다.
- 자신의 우선순위에 맞는 계획을 선택한다.

## 5. MVP 범위

### 지원 활동

- 대학 MT
- 대학 OT
- 단체 이동형 소규모 행사

### 주요 계산 카테고리

- 이동수단
- 식사
- 숙박
- 소모품

### MVP에서 제공하는 기능

1. AI 대화형 행사 계획 수집
2. 구조화된 계획 확인
3. 탄소배출량 계산
4. 행사 비용 계산
5. 탄소배출 Hotspot 분석
6. 대안 A/B/C 생성
7. 예산 및 실행 가능성 검증
8. 대안 비교
9. 최종 추천 이유 설명

## 6. MVP에서 제외하는 기능

- 로그인 및 회원가입
- 행사계획 저장
- 예약 및 결제
- 실시간 지도 및 교통 API
- 실시간 숙박 가격 API
- 모든 행사 유형 지원
- 누적 탄소감축 대시보드
- 사용자 행동 이력 기반 개인화

## 7. 성공 기준

- 사용자가 자연어로 행사 계획을 입력할 수 있다.
- 필수 정보가 누락되면 AI가 질문한다.
- 입력된 계획이 구조화된 데이터로 변환된다.
- 탄소배출량과 비용이 계산된다.
- Hotspot이 식별된다.
- 제약조건을 만족하는 대안이 비교된다.
- 결과에 계산 기준과 추정치 안내가 표시된다.
