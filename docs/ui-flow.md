
# GreenMate UI 및 사용자 흐름

## 1. 화면 목록

### ChatPage

행사 계획을 AI와 대화로 입력하는 화면.

### PlanSummary

AI가 구조화한 행사 계획을 확인하는 화면.

### ResultPage

현재안, Hotspot, 대안 A/B/C 및 추천 이유를 보여주는 화면.

## 2. 전체 사용자 흐름

```text
ChatPage
   |
   v
행사 정보 입력
   |
   v
AI 누락 정보 질문
   |
   v
PlanSummary
   |
   v
사용자 계획 확인
   |
   v
분석 실행
   |
   v
ResultPage
   |
   +--> 현재안 요약
   |
   +--> Hotspot 차트
   |
   +--> 대안 비교표
   |
   +--> 추천 이유
   |
   +--> 추정값 및 데이터 안내
```

## 3. ChatPage 요구사항

### 구성 요소

- 채팅 메시지 목록
- 사용자 입력창
- 전송 버튼
- 로딩 상태
- 오류 메시지
- 계획 진행 상태

### 동작

1. 사용자가 메시지를 입력한다.
2. /api/chat을 호출한다.
3. AI 응답을 표시한다.
4. 계획 초안을 갱신한다.
5. 분석 준비 여부를 확인한다.

## 4. PlanSummary 요구사항

### 표시 정보

- 행사 유형
- 목적지
- 참가 인원
- 행사 기간
- 이동수단
- 식사
- 숙박
- 소모품
- 예산
- 선호사항

### 동작

- 사용자가 구조화된 계획을 확인한다.
- 잘못된 내용이 있으면 수정할 수 있다.
- 필수 정보가 부족하면 분석을 실행하지 않는다.

## 5. ResultPage 요구사항

### 상단 요약

- 행사명 또는 행사 유형
- 참가 인원
- 목적지
- 분석 상태

### 현재안 카드

- 총 탄소배출량
- 총비용
- 카테고리별 배출량

### Hotspot 영역

- 배출량 상위 카테고리
- 카테고리별 비중
- 개선이 필요한 이유

### 대안 비교 영역

각 대안에 대해 다음을 표시한다.

- 대안 이름
- 변경 카테고리
- 총 탄소배출량
- 총비용
- 탄소감축률
- 비용 차이
- 조건 충족 여부

### 추천 영역

- 추천 대안
- 추천 이유
- 사용자 우선순위와의 관계

### 안내 영역

- 결과는 추정치라는 설명
- 데이터 출처 및 기준연도
- 계산에 사용한 가정

## 6. UX 원칙

- 핵심 수치를 한눈에 확인할 수 있어야 한다.
- 현재안과 대안을 혼동하지 않도록 구분한다.
- 탄소와 비용의 단위를 표시한다.
- 추천 결과만 강조하고 다른 대안을 숨기지 않는다.
- 모바일 화면에서도 주요 내용이 읽혀야 한다.
- 로딩과 오류 상태를 명확히 표시한다.
