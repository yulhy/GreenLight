
# GreenMate 데이터 사전

## 1. 목적

행사 환경 영향 및 비용 계산에 사용하는 데이터의
필드명, 타입, 단위, 의미, 출처 및 가정을 정의한다.

## 2. 카탈로그 파일

```text
backend/app/data/catalog.csv
```

## 3. 필드 정의

| 필드명 | 타입 | 설명 |
|---|---|---|
| category | string | 항목 카테고리 |
| item_id | string | 코드에서 사용하는 고유 ID |
| item_name | string | 사용자 화면에 표시할 이름 |
| carbon_factor | number | 단위당 탄소배출계수 |
| unit | string | 계산 단위 |
| reference_cost_krw | number | 참고 비용 |
| capacity_or_condition | string | 수용 인원 또는 적용 조건 |
| source | string | 데이터 출처명 |
| source_url | string | 원문 링크 |
| reference_year | integer | 데이터 기준연도 |
| assumption | string | 계산에 사용한 가정 |

## 4. 카테고리 정의

### transport

이동수단에 관한 데이터.

예시 항목:

- 승합차
- 전세버스
- 기차
- 시외버스

### food

식사 구성에 관한 데이터.

예시 항목:

- 소고기 식사
- 돼지고기 식사
- 닭고기 식사
- 저탄소 식단

### lodging

숙박에 관한 데이터.

예시 항목:

- 펜션
- 기타 MVP에서 지원하는 숙박 유형

### tableware

식기 및 소모품에 관한 데이터.

예시 항목:

- 일회용 식기
- 다회용 식기

## 5. 데이터 품질 규칙

- item_id는 중복되지 않아야 한다.
- carbon_factor는 음수가 될 수 없다.
- reference_cost_krw는 음수가 될 수 없다.
- unit은 반드시 작성한다.
- source와 reference_year를 기록한다.
- 계산 단위가 불명확한 데이터는 사용하지 않는다.
- 추정값과 실측값을 구분한다.
- 데이터 출처가 변경되면 변경 이력을 기록한다.

## 6. 계산 단위 규칙

각 항목은 반드시 다음을 명시해야 한다.

- 배출계수의 기준 단위
- 수량의 기준 단위
- 비용의 기준 단위
- 필요한 환산 방식
- 적용 조건

예를 들어 이동수단은
인원 기준인지, 차량 기준인지, 거리 기준인지 구분해야 한다.

## 7. 데이터 검증 체크리스트

- [ ] 모든 항목에 고유 ID가 있는가?
- [ ] 단위가 명확한가?
- [ ] 출처 URL이 있는가?
- [ ] 기준연도가 기록되어 있는가?
- [ ] 계산식에 필요한 값이 모두 있는가?
- [ ] 행사 규모에 적용 가능한 데이터인가?
- [ ] 데이터의 가정이 문서화되어 있는가?
