
# GreenMate 테스트 계획

## 1. 테스트 목적

- 탄소배출량 계산의 정확성 검증
- 비용 계산의 정확성 검증
- Hotspot 선정 규칙 검증
- 대안 후보 필터링 검증
- API 요청 및 응답 검증
- AI 대화의 필수 정보 수집 검증

## 2. 계산 모듈 테스트

### TC-CALC-001. 단일 항목 계산

**입력**

- 수량: 10
- 배출계수: 2

**기대 결과**

```text
탄소배출량 = 20
```

### TC-CALC-002. 여러 카테고리 합계

- 이동수단
- 식사
- 숙박
- 소모품

각 카테고리의 결과 합계가 전체 합계와 일치해야 한다.

### TC-CALC-003. 잘못된 수량

- 음수 수량
- 0 수량
- 숫자가 아닌 값

각 입력에 대해 정의된 검증 규칙을 적용한다.

### TC-CALC-004. 데이터 누락

배출계수가 없는 항목을 계산할 때
임의의 수치를 사용하지 않아야 한다.

## 3. Hotspot 테스트

### TC-HOTSPOT-001

배출량 상위 2개 카테고리가 선정되는지 확인한다.

### TC-HOTSPOT-002

3위 카테고리의 배출 비중이 10% 이상이면 포함되는지 확인한다.

### TC-HOTSPOT-003

전체 배출량이 0일 때 0으로 나누는 오류가 발생하지 않는지 확인한다.

## 4. 대안 필터 테스트

### TC-RULE-001. 예산 초과

예산을 초과하는 대안은 제외한다.

### TC-RULE-002. 인원 부족

참가 인원을 수용할 수 없는 항목은 제외한다.

### TC-RULE-003. 제외 항목

사용자가 제외한 항목은 후보에서 제거한다.

### TC-RULE-004. 현재 항목 중복

현재 선택과 동일한 항목은 대안 후보에서 제외한다.

### TC-RULE-005. 접근성

목적지와 이동 조건을 만족하지 못하는 후보는 제외한다.

## 5. API 테스트

- GET /api/health 정상 응답
- POST /api/chat 정상 응답
- POST /api/chat 필수 정보 누락
- POST /api/plans/analyze 정상 분석
- POST /api/plans/analyze 잘못된 요청
- GET /api/catalog/categories
- GET /api/catalog/items

## 6. 프론트엔드 테스트

- 채팅 메시지 표시
- 전송 중 로딩 표시
- API 오류 표시
- 계획 초안 표시
- 분석 실행 버튼 상태
- 결과 차트 표시
- 대안 비교표 표시
- 모바일 화면 레이아웃
