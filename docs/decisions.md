## DEC-001. 수치 계산을 Python에서 수행

### 날짜

YYYY-MM-DD

### 결정

탄소배출량과 비용 계산은 Python 계산 모듈이 담당한다.

### 이유

LLM의 임의적인 수치 생성을 방지하고
동일한 입력에 대해 재현 가능한 결과를 얻기 위해서다.

### 영향

- Calculator 모듈 필요
- CSV 데이터 필요
- 계산 모듈 테스트 필요
- LLM은 설명 역할 중심으로 제한

### 상태

## DEC-002. MVP는 MT/OT 시나리오에 집중

YYYY-MM-DD
