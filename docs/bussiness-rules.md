
# GreenMate 비즈니스 규칙

## 1. 목적

행사 계획을 탄소배출량과 비용 측면에서 분석하고
실행 가능한 저탄소 대안을 구성하기 위한 규칙을 정의한다.

## 2. 탄소배출량 계산

### 기본 원칙

탄소배출량은 카탈로그에 등록된 배출계수와
입력된 수량을 사용하여 계산한다.

### 일반적인 계산식

```text
항목별 탄소배출량
= 수량 × 탄소배출계수
```

단, 이동수단처럼 거리나 탑승 인원이 계산에 필요한 항목은
해당 데이터의 정의에 맞는 별도 계산식을 사용한다.

### 필수 검증

- 계산 단위가 일치해야 한다.
- 배출계수가 존재해야 한다.
- 수량이 유효해야 한다.
- 데이터가 부족하면 계산을 중단하거나 확인 필요 상태를 반환한다.

## 3. 비용 계산

### 기본 계산식

```text
항목별 비용
= 수량 × 참고 비용
```

실제 비용 산정에 추가 조건이 필요한 경우
해당 조건과 가정을 명시한다.

### 주의사항

- 참고 비용과 실제 결제 비용을 구분한다.
- 실시간 가격이 아니면 추정치로 표시한다.
- 비용이 없는 항목은 임의로 0원 처리하지 않는다.

## 4. Hotspot 선정

### 기본 규칙

1. 카테고리별 탄소배출량을 계산한다.
2. 배출량을 내림차순으로 정렬한다.
3. 상위 2개 카테고리를 Hotspot으로 선정한다.
4. 3위 카테고리의 전체 배출 비중이 10% 이상이면 포함한다.

### 예외

- 전체 배출량이 0이면 비중을 계산하지 않는다.
- 데이터가 부족한 카테고리는 분석 결과에 명시한다.

## 5. 대안 후보 생성

대안은 현재 선택과 동일한 카테고리 안에서 탐색한다.

예시:

```text
현재: disposable tableware
대안: reusable tableware
```

다른 카테고리의 항목으로 임의 대체하지 않는다.

## 6. 실행 가능성 검증

각 대안은 다음 조건을 검증한다.

### 예산

```text
대안 총비용 <= 허용 예산
```

허용 예산은 기본 예산과 사용자가 설정한
추가 비용 허용 범위를 함께 고려한다.

### 인원

- 행사 참가 인원을 수용할 수 있어야 한다.
- 차량 및 숙박의 수용 인원을 검증한다.

### 거리 및 접근성

- 이동수단이 행사 이동거리에 적용 가능한지 확인한다.
- 목적지 접근성 조건을 확인한다.

### 제외 항목

- 사용자가 제외한 항목은 후보에서 제거한다.
- 제외 조건은 대안 생성 이후가 아니라 후보 필터링 단계에서 적용한다.

## 7. 대안 비교

각 대안에 대해 다음을 계산한다.

```text
탄소감축량
= 현재안 탄소배출량 - 대안 탄소배출량
```

```text
탄소감축률
= 탄소감축량 / 현재안 탄소배출량 × 100
```

```text
비용 차이
= 대안 총비용 - 현재안 총비용
```

현재안의 탄소배출량이 0이면 감축률을 계산하지 않는다.

## 8. 추천 이유 생성

LLM은 다음 데이터를 입력받아 추천 이유를 작성한다.

- 현재안의 탄소배출량
- 현재안의 비용
- 대안별 탄소배출량
- 대안별 비용
- 탄소감축률
- 비용 차이
- 제약조건 충족 여부
- 사용자 우선순위

LLM은 위 데이터에 없는 수치를 만들어내지 않는다.

## 9. 추천 결과의 의미

추천은 사용자의 우선순위와 제약조건을 고려한
의사결정 지원 결과다.

화면에는 다음을 구분하여 표시한다.

- 계산된 수치
- 등록된 데이터
- 추정값
- 추천 이유
- 사용자가 직접 선택할 수 있는 대안
